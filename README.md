
# Supplementary for Paper HY-MAST
This is the supplementary material for the paper *HY-MAST: PROBING THE FRAGILE FOUNDATIONS OF MUSIC UNDERSTANDING IN MULTIMODAL LLMs*. 

HY-MAST is a holistic music benchmark designed to automatically generate diverse music understanding tasks and multimodal musical content.
It enables systematic evaluation of music understanding capabilities in multimodal large language models (MLLMs).
The supplementary material includes the following sections:

- **Codes**  
    The **Code_Fragments** folder provides partial code snippets, including:  
    Automatic fundamental perception questions generation tools:
    Code_Fragments/Auto_Benchmark_Test_for_LLM_main.py  
    Automatic synthesis tools:
    Code_Fragments/Algorithm_for_Music_Synthesize.py  
    Batch generated abc to wav tools:
    Code_Fragments/lm_gen_abc_to_audio.py  
    pseudorandom tools:
    Code_Fragments/pseudorandom_tools.py
- **Music samples**  
    The folder **online_sys_music_files** stores the audio files required by the demo page.
- **Demo and details**  
    The file ***Test demonstration.html*** serves as a demo webpage. It supplements method details and presents cases for Fundamental Perception and Theoretical Knowledge Evaluation.
